# Swanky Games website

Static site for swankygames.xyz: landing page, Tidebound game page, support and privacy. No build step.

- `index.html`: landing page
- `tidebound/index.html`: game page
- `support/`, `privacy/`: store-required pages (privacy is a draft)
- `assets/`: styles, script and screenshots

Preview locally: `python3 -m http.server 8080`, then open http://localhost:8080
